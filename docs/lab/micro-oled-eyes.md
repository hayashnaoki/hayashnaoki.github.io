# Micro OLED Eyes

2026 \| DFAB \| CPP

A dual-display hardware project using a Seeed Studio XIAO RP2040 and two SH1106 OLED screens to animate synchronized eye tracking movements.

[GitHub](https://github.com/hayashnaoki/micro-oled-eyes/tree/main)

I wanted to try this out to test Antigravity IDE in combination with PlatformIO and to learn proper version control using GitHub.
The transition from Arduino IDE to Antigravity/PlatformIO was very smooth, and Antigravity comes with automated configuration features for managing libraries and boards.
