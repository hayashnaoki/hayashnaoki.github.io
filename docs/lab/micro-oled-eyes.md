# Micro OLED Eyes

2026 \| DFAB \| C++

A quick hardware exploration using a Seeed Studio XIAO RP2040 and twin SH1106 OLED displays for animated eye tracking. This project was a chance to test [Antigravity IDE](https://antigravity.google/product/antigravity-ide) with [PlatformIO](https://platformio.org/) and step up my Git workflow beyond the standard Arduino IDE.

**Animation**

- Smooth blinks: Easing curves make eyelid movements feel far more natural.
- Natural drift: Subtle vertical movement keeps the eyes alive even when idle.
- Slight cross-eye: Inward focal alignment adds immediate depth and personality.
